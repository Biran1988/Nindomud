Nindo_mud Visual Builder

Works offline in your browser. Open an exported in-game area or start a new one, edit the grid, then export one JSON package.

Rooms snap to the grid. Select a source room, press Connect rooms, then click a destination. The grid sets the compass direction and adds both exits. Use Connection type for vertical or inside/outside exits. Moving a linked room updates its compass exits.

Saved projects

Every change autosaves to this browser, even if the area is unfinished. Save a portable project backup to resume on another computer; area JSON is only for importing into the game.

Game package

On your server, place the exported file in data/area_imports/. In game, use area import filename.json check, then area import filename.json as Implementor. A game export can update its own area; a new package adds unused VNUMs. The check command validates without changing the game.
